# data/samples/ — 合成样例与植入真值（M4 落盘）

**状态**：⬜ M4 落盘（当前为占位）。

- `cases.json` — 合成文案样例集（假品牌白名单；每条登记 `expect_hits`（词+位置）与 `expect_verdict`）；
- `manifest.json` — 计数 / 覆盖"总数-采样数"双登记 / 采样清单 / 验收门槛（**数据非代码**）。

纪律（详见 `plan/05-数据计划.md` §5 与 `plan/04-模块详设.md` §5）：

- 生成器 `tools/gen_cases.py` 确定性产出（枚举式、无随机、无时间戳），配 `--check` 位级一致守门；
- 真值**只存"输入与期望"**——出现 `observed` 类字段即视为缺陷；
- 覆盖三类边界：语境豁免 / 同词异类 / 未命中（负样例）；
- 基准 `tools/bench.py` 一条命令复现评测，断言命中集合（词+位置）**精确匹配**。
