# 词表候选工作台账（采/拒记录）

**基准日**：2026-10-15。来源快照：`es3344520/advertising-limit-words` 的 `Dete.txt`（191 个去重词面，经 api.github.com base64 通道获取；raw.githubusercontent.com 直连被重置）＋ `dx2020z/ad-redline-guardian` 的 `references/banned-words.md`（分类参照）。

**去向口径**：

- **采（进规则包）**：逐条挂锚点（`literal` 词面逐字见于冻结条款正文 / `variant` 带 note 说明语义类属）＋ 定风险 ＋ 写确定性建议 → `references/wordlists/*.json`（仅 `verified`）；
- **拒（不进规则包）**：锚点挂不住 / 否定易词（词面易造成"无副作用"类反向误报）/ 单字与超泛词面 / 语境强依赖无法给确定性建议 → 留本台账，**引擎不加载**。

**当轮采拒计数（实测）**：来源 191 词 → 采 67（另 66 条自 banned-words.md 分类参照增补，共 133 条 verified 入包）＋ 拒 124（下表）。
