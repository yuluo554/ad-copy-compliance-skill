# references/ — 三层规则包（规则与代码分离，可版本化、可审计）

本目录是**规则来源**，与 `data/`（评测素材）分工：`references/` 逐条挂原文核对，`data/` 承载合成样例与植入真值。

```
references/
├── statutes/    # 第一层：法条原文冻结文本
├── platforms/   # 第二层：分平台规则（人工摘录冻结）
└── wordlists/   # 第三层：分类词表
```

## 第一层 `statutes/` — 法条原文冻结

- 来源：`samr.gov.cn` 直连可解析（✅ 已核对，见 `data/README.md` §1）。
- 内容：《中华人民共和国广告法》§9 绝对化用语 / §16 医疗 / §18 保健食品 / §28 虚假广告；《互联网广告管理办法》；《医疗广告管理办法》§6/§7 禁止性。
- 纪律：**冻结字节件**（登记 sha256，`.gitattributes` 禁 EOL 归一化）；每条带来源 URL + 基准日 + 查证状态。
- ⚠️ 广告绝对化用语执法指南（一）（二）**存在但不涉及绝对化用语认定口径，勿误标为认定依据**。

## 第二层 `platforms/` — 分平台规则

- 来源：淘宝 / 抖音 / 小红书 / 视频号社区规范 —— **官方页纯 JS 渲染 ⬜ 不可自动抓**，故为**人工摘录冻结件**。
- 纪律：每份摘录件登记 **平台名 + 摘录日期 + 原页 URL + 摘录人 + 摘录范围**；**不得声称"官方实时口径"**。

## 第三层 `wordlists/` — 分类词表

- 来源：公开整理词表（`es3344520/advertising-limit-words` 的 `Dete.txt` 去重后 191 词（M1 实测）；`dx2020z/ad-redline-guardian` 的 `references/banned-words.md` 分类更结构化），**非官方整理**。
- 类别：绝对化用语 / 医疗 / 保健食品 / 行业。
- 纪律：每条须带 **来源 + 类别 + 风险等级 + 依据条款锚点**；**未挂原文核对的词条不得被扫描器加载生效**；显式标注"**非官方整理，法条原文为准**"。
