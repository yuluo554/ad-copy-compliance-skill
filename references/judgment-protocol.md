# 判定协议（Judgment Protocol）—— 扫描层之上的语境分层判定 v0.1

> **定位**：本协议是**宿主 Agent（Claude Code / Codex 会话内）执行语境判定时的行为规范**。
> 本项目自身无外发通路、无 LLM 客户端（决策 D-2）；扫描层零 LLM、零网络（K7）。
> 判定层只对扫描层已命中的候选做注释，**不可用即降级，不硬造结论**。
> 口径依据：`plan/04-模块详设.md` 模块④；K1/K10/K12。

---

## 0. 输入 / 输出

- **输入**：扫描层命中集合（`scripts/check.py` stdout JSON）＋ **同一会话内**的原始文案。
  判定层只处理扫描层已命中的条目；扫描漏了的表述不由判定层补——那是词表 backlog
  （补词走 `data/wordlist-candidates.md` 台账＋重生成，不静默扩规则）。
- **输出**：对**每条命中**的注释副本——复制扫描层字段后**只追加**三个字段（K10）：

| 追加字段 | 语义 |
|---|---|
| `verdict` | `confirmed` / `exempt` / `uncertain`（三态见 §1） |
| `verdict_reason` | 判定理由：一句话说明语境证据与结论关系；`exempt` 必须给可核实的豁免依据；`uncertain` 必须说明**为何无法判定**（§1.3） |
| `verdict_anchor` | 依据锚点：`{doc, clause}`（法条，如 `advertising-law/第九条`）或 `{doc}`（平台摘录，如 `platforms/shipinhao`）；`uncertain` 时可为 `null`，`confirmed` 时不得为空 |

- **不得**新增、删除、移动任何命中；**不得**改动 `word / category / risk / line / col / context / suggestion`
  任一扫描字段（结构测试锁定：`tests/test_judgment_protocol.py`）。
- **meta 声明**：判定产物附 `meta` 对象：`{"judgment": "on" | "off" | "failed", "note": "..."}`。
  - `on`：判定层正常工作；
  - `off`：判定被关闭（用户要求"只扫描不判定"）→ 所有命中标 `uncertain`，note 须含"仅扫描结果，未经语境判定"；
  - `failed`：判定执行失败（如会话中断、证据不可得）→ 同上降级，note 须含降级原因。
- **产物标注**：判定层产物必须在呈现时明示"判定层产物，可复跑性弱于扫描层"（扫描层同输入逐字节复现；判定含语义裁量）。

---

## 1. 三态定义

### 1.1 `confirmed` —— 语境中属明确受限表述

命中词在当前语境中**直接构成**受限表述，无豁免特征。

典型情形：
- 直接向消费者作出的宣称（无引述、无比对、无法定专名语境）中使用绝对化用语——
  如商品标题/详情页直陈"国家级""最佳"（《广告法》第九条第三项）；
- 医疗/保健食品语境下的疗效断言与保证——如"保证治愈""包治百病"
  （《医疗广告管理办法》第七条；《广告法》第十六条）；
- 保健食品宣称疾病预防/治疗功能（《广告法》第十八条）。

要求：`verdict_reason` 说明为何属直接宣称；`verdict_anchor` 给到条款（不得为空）。

### 1.2 `exempt` —— 语境豁免（有依据，必须给理由＋锚点）

命中词虽出现，但语境使其**不构成**受限表述。**豁免必须有可指认的依据，逐条给理由＋锚点**；
"我觉得没问题"不构成豁免依据。

典型情形（封闭列举，M3 版）：
- **引述性使用**：引用法律条文原文、引用他人原话/法院判决/官方文书的直接引语；
- **法定专名与官方认定表述**：法定名称、官方认定的规范表述（如获奖名须同时可核实其官方性）；
- **明确的非宣称语境**：内部讨论稿、明确标注"示例/反例"的教学文本等不面向消费者的语境；
- **事实性限定语生效**：如"某年销量第一"附可核实的统计口径与出处——注意：**只有限定语
  本身可逐字核实**才算豁免；口径模糊（"据多方统计"）不得豁免，应判 `uncertain`。

要求：`verdict_reason` 给出属上述哪一类豁免＋核实路径；`verdict_anchor` 指向依据
（法条条款或平台摘录件；引述类可指认被引对象）。**协议不承认默认豁免：无法给出锚点即不得判 exempt。**

### 1.3 `uncertain` —— 需人工复核（非垃圾桶）

判不了 `confirmed` 也给不出豁免依据时判 `uncertain`，**必须说明"为何无法判定"**。
`uncertain` 不是兜底垃圾桶：每个 `uncertain` 的 `verdict_reason` 都要能回答
"缺什么证据/什么语境歧义"。

典型情形：
- **证据不足**：如"销量第一"未附统计口径——无法核实也无法排除；
- **语境歧义**：命中段前后文不足以区分宣称/引述（如截断的标题）；
- **判定层不可用**：降级路径（§3）下全部命中标 `uncertain`。

要求：`verdict_reason` 说明缺失的证据或歧义点；`verdict_anchor` 可为 `null`（有倾向性依据时仍应给出）。

## 2. 适用边界（何语境可豁免 / 何语境必须 uncertain）

| 语境特征 | 判定 |
|---|---|
| 面向消费者的宣称文案 + 无豁免特征 | `confirmed`（锚点必给） |
| 直接引语（法条/判决/他人原话，逐字可核实） | 可 `exempt`（须指认被引对象） |
| 法定专名 / 官方认定规范表述（可核实） | 可 `exempt` |
| 内部稿 / 标注"示例""反例"的非宣称语境 | 可 `exempt` |
| 事实性限定语**逐字可核实**（口径+出处完整） | 可 `exempt` |
| 事实性限定语口径模糊（"据多方统计"） | 必须 `uncertain` |
| 证据不足以核实或排除 | 必须 `uncertain` |
| 前后文不足以区分宣称/引述 | 必须 `uncertain` |
| 判定层关闭/失败 | 全部 `uncertain` ＋ 降级声明（§3） |

边界纪律：
- 判定**不输出合规结论**（K12）：三态是"候选风险分层"，不是"违规/合规"判定；
  呈现时必须携带免责声明（§5）。
- 扫描层零 LLM 不变；判定层不可把词表外表述"补录"成命中，也不可把命中"划掉"。
- 平台摘录件（`references/platforms/`）是人工快照、非官方实时口径——引用其作锚点时
  必须带摘录日期意识，`verdict_anchor` 注明 `{doc}` 即可，不冒充法条。
- 判定由同一会话内的宿主 Agent 逐条独立作出；**禁止**批量"整段没问题"式跳过——
  每条命中都要有自己的一行注释。

## 3. 降级路径（必须可测试）

| 状态 | 触发 | 行为 |
|---|---|---|
| 判定关闭（off） | 用户要求"只扫描、不判定"，或宿主未执行判定步骤 | 输出纯扫描结果；若有命中，每条标 `uncertain`，`meta.judgment="off"`，note 显式声明"仅扫描结果，未经语境判定" |
| 判定失败（failed） | 会话中断、证据不可得、协议执行出错 | 同上：全部命中标 `uncertain`，`meta.judgment="failed"`，note 含失败原因 |
| 判定可用（on） | 正常执行 | 逐条三态注释；不得静默跳过任何一条 |

降级语义铁律：
- 降级时**扫描字段一字不动**（K10）——降级只追加 `verdict/verdict_reason/verdict_anchor` ＋ `meta`；
- 降级声明必须**显式出现在输出中**（`meta.note`），不得只在对话里口头说明；
- **零命中 ≠ 合规**（K12）：零命中时同样输出免责声明与"未检出词表命中"措辞。

降级路径由结构测试锁定（`tests/test_judgment_protocol.py`：off → 纯扫描输出＋全 uncertain＋声明；
failed → 同；on → 注释副本不改任何扫描字段）。

---

## 4. 判定理由与锚点字段口径

- `verdict_reason`（str，非空）：一句话；三态各自的下限要求见 §1。
  反例（不合格）："有问题"/"没问题"/"应该是违规的"——不说明语境证据者视为未执行判定。
- `verdict_anchor`（object or null）：
  - 法条依据：`{"doc": "advertising-law", "clause": "第九条"}`（doc 与 `references/statutes/` 冻结件文件名一致，不含扩展名）；
  - 平台摘录依据：`{"doc": "platforms/shipinhao"}`；
  - `confirmed` 时不得为 `null`；`uncertain` 时可为 `null`；`exempt` 时不得为 `null`。
- 追加字段只出现在判定层产物；扫描层 stdout（`scripts/check.py`）的契约字段**保持 7 个不变**（K1，
  `HIT_FIELDS` 锁定）——判定层是 Agent 会话内的注释行为，不改扫描器输出契约。

---

## 5. 免责与统一措辞（K12）

判定层产物（含降级产物）呈现时**强制携带**以下口径，不得删改弱化：

1. "本结果为辅助自查提示，不构成法律意见、不构成合规保证、不构成行政认定；正式结论以主管部门口径与专业律师意见为准。"
2. "**零命中 = 未检出词表命中，不等于合规**"——即使全部命中判 `exempt`，也只说明"词表命中的条目经语境判定可豁免"，不等于文案整体合规。
3. 判定层产物须标注"**判定层产物，可复跑性弱于扫描层**（含语义裁量）"。
4. 判定层执行者是宿主 Agent，判定意见随会话上下文变化——重要决策须人工复核，`uncertain` 条目**必须**人工复核。

## 附录 A：三态示例（对一条真实命中的三种判定）

扫描层命中（同一输入、同一位置，扫描字段三例完全一致）：

```json
{"word": "国家级", "category": "绝对化用语", "risk": "high",
 "line": 1, "col": 1, "context": "国家级非物质文化遗产名录收录", "suggestion": "……"}
```

输入文案为合成示例文案（见 `tests/test_judgment_protocol.py` 夹具），三例仅语境不同：

**例 1 — `confirmed`**：文案为面向消费者的商品详情页直陈：

```json
{"word": "国家级", "category": "绝对化用语", "risk": "high",
 "line": 1, "col": 1, "context": "国家级工艺大师监制", "suggestion": "……",
 "verdict": "confirmed",
 "verdict_reason": "商品详情页直接向消费者宣称，无引述或法定专名语境，属《广告法》第九条第三项明令的绝对化用语。",
 "verdict_anchor": {"doc": "advertising-law", "clause": "第九条"}}
```

**例 2 — `exempt`**：文案为对官方名录的客观陈述，"国家级"是法定名录名称的组成部分：

```json
{"word": "国家级", "category": "绝对化用语", "risk": "high",
 "line": 1, "col": 1, "context": "国家级非物质文化遗产名录收录", "suggestion": "……",
 "verdict": "exempt",
 "verdict_reason": "'国家级非物质文化遗产名录'为国务院公布的法定名录名称，属法定专名的组成部分，非自证式绝对化宣称；核实路径为国务院公布的名录文本。",
 "verdict_anchor": {"doc": "advertising-law", "clause": "第九条"}}
```

**例 3 — `uncertain`**：文案为孤立的截断标题，无法区分宣称与引述：

```json
{"word": "国家级", "category": "绝对化用语", "risk": "high",
 "line": 1, "col": 1, "context": "国家级认证", "suggestion": "……",
 "verdict": "uncertain",
 "verdict_reason": "前后文不足以判断'国家级'是自证宣称还是对某认证机构名称的引述；缺失认证名称与颁发机构信息，无法核实或排除。",
 "verdict_anchor": null}
```

三例中 `word/category/risk/line/col/context/suggestion` 七个扫描字段逐字一致——判定层只追加三个字段（K10）。
