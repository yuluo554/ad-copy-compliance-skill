## 3. 验收门 checklist（项目裁剪版）

> 口径：与 sprint 验收门一一对照，逐项标注落点；**不适用项必须显式标注理由**，不留空白。

### 计划与数据

- [ ] plan/ 与 data/ 台账齐全、来源可溯；里程碑状态随棒回写（`plan/00`、`06`、`07`）
- [x] 数据底座预检留档：samr 直连可得性已实测（出题期 ✅）；M1 冻结件入仓＋"原文逐字包含断言"＋双 sha256（✅ 2026-10-15：3 部冻结，`references/statutes/README.md` 登记双 sha256，`build_statutes --check` 位级一致）
- [ ] ⚠️ 骨架对源数据的猜测必须被 M1 实测**勘误**并同步（文件命名/条款抽取正则/字段），勘误记录进台账与决策记录

### 规则与门控

- [ ] 规则包冻结＋status 门控：词表/法条为冻结构（禁手改；`--check` 位级守门）；`verified`＋锚点解析双门控；**未启用清单**显式可见（✅ M1 冻结＋M2 门控负例/部分坏文件测试锁）
- [x] "零字面量"对应形态：**`scripts/` 源码不得内嵌词表词面**（token 由规则包运行时实算）＋"规则只一处定义"扫描断言（✅ M2 初版：≥3 字词面门禁，D-10；M5 完整化）
- [ ] 缺锚点/锚点解析不到的条目**拒绝加载**并在未启用清单列出原因（✅ M1 门控实现＋M2 测试锁：status 非 verified/条款解析不到/literal 词面未见于条款/锚点文件缺失逐因断言）

### 判定语义（不虚高）

- [ ] **零命中 ≠ 合规**：统一措辞（K12）；`exempt` 必须有理由＋锚点；`uncertain` 必须说明"为何无法判定"（非垃圾桶）；降级（关闭/失败）声明显式
- [ ] 判定层只注释不改变扫描字段（结构测试）；扫描层零 LLM（import 门禁）

### 基准

- [ ] `bench` 一条命令可复现；exact-match（词＋位置，双向集合相等）达标并写进 README
- [ ] 真值只存"输入与期望"（禁 `observed` 类字段——出现即红）
- [ ] 覆盖"总数/采样数"双登记＋采样清单；抽样非穷举显式声明
- [ ] 每套件探活（注入缺陷→必红；打到端到端入口）；退出码三语义（0/1/2）锁测试；门槛随 manifest（数据非代码）
- [ ] 每次里程碑收尾复跑基准防回退

### 测试与 CI

- [ ] 测试全绿（含失败路径：缺文件/非 UTF-8/坏词表/词表目录缺失）（✅ M2 快照：36 项双解释器绿；失败路径含坏词表文件跳过＋未启用清单测试；M5 再全量复核）
- [x] 新增/改写的守门做过**变异验证**（弄坏被测行为→门必红；弄坏后仍绿=假门）（✅ M2：非重叠破坏/退出码破坏/门控破坏 3 处注入全红，已还原复绿）
- [ ] 编码守卫覆盖所有会打印的可执行入口（`scripts/`＋`tools/`，含后期新增）
- [ ] 端到端演示通过（CLI＋skill 调用；扫描零网络，断网可跑）
- [ ] CI：M0–M5 记"本地等价校验（未接远端，CI 待首推验证）"；M6 首推全绿＋**push/run 逐条对账**（含 tag push 实测记录）
- [ ] dev 与 CI 的 extras/依赖集合一致（`requirements-dev.txt` 同源安装）；干净环境与 dev 的收集数对账（同一依赖集合下）

### 发布与收尾

- [ ] 干净环境验证（新 clone＋全新 venv＋README 逐条，退出码语义如实记录）
- [ ] 脱敏四步＋仓库内可复跑扫描器（tracked/history/messages 三模式＋selftest 阳性对照）；扫描器 token 运行时实算；提交元数据邮箱检查（本仓 local 已配 noreply；global 为个人邮箱——提交/amend 后须核对 ae 与 ce 两字段）
- [ ] 发布物本体已验：Release 附件真下载→sha256 比对→解压中立目录验证（zip：`ZIP_STORED`＋固定时间戳＋条目排序，两次打包逐字节一致）
- [ ] 首推顺序：先私有→CI 绿→tag/Release→切公开（三清再切：历史三扫 0 硬门/坏 blob 修净/失败 run 删）；**对外动作（建仓/tag/Release/topics/可见性）先经用户确认**
- [ ] 收尾固化：topics；README 状态行转正；材料固化；缓议项清零（含显式"跳过"决策）；计数全仓同步（当轮实测）

### 显式不适用（裁剪说明）

- 打包/exe/安装面四面/零政策字面量/双重门控/版本对照 diff：**不适用**——本项目为 Skill＋CLI 形态（无 exe 打包、无第三方安装面、非政策数值工具）；对应形态已裁剪为"词面不内嵌门禁 / import 白名单门禁 / requirements-dev 同源"。
