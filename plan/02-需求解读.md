## 2. 目标用户与使用场景

- **用户**：电商运营 / 内容创作者 / 代运营 / 个体商家——要写推广文案、要在平台发布内容的人。
- **场景**：**发布前自查**。输入 = 商品标题、详情页文案、直播话术、朋友圈文案、短视频脚本；输出 = 逐句标红 + 替换建议 + 依据条款 + 免责声明。
- **交付形态**：Agent Skill（Claude Code / Codex 可调用，粘贴即用）；同附 CLI（`scripts/check.py`）供脚本与 CI 直用；MCP 查询层为扩展（P1）。

## 4. 边界与非目标

**题面既定边界（红线，逐条保留）**：

- **不做法律意见**：输出为辅助自查提示，不构成法律意见/合规保证/行政认定；`SKILL.md` 与输出强制携带免责声明。
- **不做自动发布/自动改写上线**：只给替换建议供人决策；不对接任何平台发布接口。
- **隐私红线**：纯本地、零上传；扫描层零网络；判定层由宿主 Agent 在会话内按协议执行且可关闭（关闭后降级为纯扫描）；本项目自身不含任何外发通路（外部 API 适配如做，只允许作为显式可选项存在于扩展设计，默认无）。
- **品牌隔离**：不引用任何真实品牌违规案例；基准与演示一律假品牌名/假商品白名单；公开文档不涉其余项目领域。
- **首期范围**：仅文案自查五模块；MCP / 多平台 / 批量 CI 为扩展项。
- **词表性质**：公开整理词表**非官方**，逐条标注来源与"非官方整理，法条原文为准"；平台摘录件不得声称"官方实时口径"。
- **数值口径**：词条数与样例数**不预设硬数字**，以"挂原文核对后的词条"与"构造真值后的样例"为准（末态回填）。

**补充非目标（本仓自身的形态约束）**：

- 不做桌面 exe / GUI 程序（形态固定为 Skill + CLI，不做打包分发）；
- 不做服务端 / 云函数 / 账号体系；
- 不做"全量法律法规检索"（仅冻结与判定相关的 3 部文本）；
- 不做平台规则的"官方实时同步"（摘录件为冻结快照，注明日期）；
- **不输出"合规"结论**：零命中 = "未检出词表命中"，不等于合规——该措辞纪律贯穿输出、文档与 README。
